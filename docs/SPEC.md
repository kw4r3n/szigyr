# Szigyr Language Specification v1

Normative core spec (`szigyr`, `.szigyr`). Full stdlib/caps/flags/examples: `docs/STDLIB.md` (`szigyr://stdlib`) & `szigyr://builtins`. Unlisted syntax/types/built-ins rejected (`E1000`/`E2000`).

## 0. Principles
1. TS-parseable `.szigyr`, sound ops (`indexOf`->`usize|null`, `JSON.parse`->`Result`, `charCodeAt` `T002`, int ovf `T001`).
2. 3 layers: `managed` (JS GC), `strict` (`"use owned"`, C/Wasm, no in-kernel GC/RC; `Vec`/`Pool`/`Arena` JS-backed across boundary), `rt` (`"use rt"`, `strict` sans alloc/auth/rec).
3. Non-C-only parity across JS/C/Wasm (rets, `Mut` writes, stdout, trap code+pos).
4. Explicit param/ret/layer/auth/generic bounds (`T extends ...`); local-only inference (locals, call targs).
5. No ambient globals (`console`,`Date`,`Math.random`,...); effects via capability args.

## 1. Modules & Top-Level
- **ESM only**: Named `import`/`export` (`import {a as b} from "./x.szigyr"`, `export {a}`, inline `export`), named re-exports (`export {a,b as c} from "./x.szigyr"`), ns imports (`import * as ns from "./x.szigyr"`, `ns.T` type/`ns.v` val; export `ns` `E7001`), `import type`/`export type` (`import {type T,v}`) on `.szigyr`/`c:` (value use `E2002`). Paths: `./`/`../` ending `.szigyr` (canonical realpath), `"npm:<pkg>"` (§7), `"c:<pkg>:<header>"` (§9). Acyclic chains any depth; cycles fail at use (`E2000`). Forbidden: `export default`/`export *` (`E1003`), `import()`, `require()`, local default/side-effect imports, `import type` on `npm:`, `c:`/`npm:` re-exports, missing target (`E7001`).
- **Top-level**: `import`/`export`, `function`, `type`, `interface`, `class`, `const` (typed `E2006`; lit or immutable rec/arr lit incl. `const {a,b:c}:T={...}`; `Native & Copy` readable in `strict`/`rt`), `test(...)`, `declare module "c:..."`. Top `let` or mut/non-lit `const`/`static`: `E5002`.
- **Reserved (`E1000` decl)**: §12 globals, §13 reserved, `__szigyr_rt*`, `__proto__`/`constructor`/`prototype`/`toString`/`valueOf`. Values/types share dup check (`E1000`).

## 2. Layers, Directives & Functions
File-top directive (before `import`) sets default layer for top-level `function` (not methods/`test`); fn-top overrides. Bad directive: `E1000` (`"use unsafe"` `E1009`; `"use strict"` disallowed—use `"use owned"` or omit for `managed`). No `"use managed"`: omit file-top directive when mixing `managed`+`strict`/`rt` in one file.
- *(none)*=`managed` (JS GC, `async`/`await`, closures, `Array`/`Map`/`Set`/`string`/`npm:`); `"use owned"`=`strict` (ownership/borrow, `Native` data, C/Wasm); `"use rt"`=`rt` (`strict` sans alloc `E4004`, auth `E4006`, rec `E4005`); `"use unsafe"`=mod on `strict`/`rt` fn (`Ptr`/`ConstPtr`/`CType`/`CStruct`/`CHandle`, `c:`, `cfn`; `E1009` elsewhere).
- **Calls (`E4001`)**: `managed`->{all above + safe-sig `strict+unsafe`}; `strict`->{`strict`,`rt`,safe-sig `strict+unsafe`}; `rt`->{`rt`}; `rt+unsafe`->{`rt`,`rt+unsafe`} (`strict+unsafe` w/ raw `Ptr` needs `"use unsafe"`; `rt+unsafe` omits `Ffi` so only callable from `rt+unsafe`/`cfn`).
- **Arrows/fn-exprs**: Inherit layer, no directives; forbidden in `strict`/`rt` (`E4003`) except `ensures((r:R)=>...)`.
- **Fn params (`strict`/`rt`)**: Param/nested-param `(a:A)=>R` OK (not ret/locals/fields/targs `E4003`, except `Ptr`/`ConstPtr` fn ptrs §9). Args: top non-generic `strict`/`rt` fn or forwarded param (`E4003`; `rt`->`rt`; safe rejects `rt+unsafe` `E4001`); specialized.
- **Recursion**: Poly-rec growing tparam (`f<Box<T>>`) in `strict`/`rt`: `E4010`. Any `rt` call cycle (incl. fn params, even uncalled): `E4005`.

## 3. Types & Capability Matrix

### 3.1 Primitives & Numerics
- **Prims**: `boolean`, `string` (`managed`), `null` (1B, all), `void` (ret only `E2002`, + `Ptr<void>`/`ConstPtr<void>`), `unknown` (`managed`), `never` (bottom/ret only; `strict`/`rt` param `E4002`). No `undefined` (`E2000`).
- **Nums**: `i8`, `i16`, `i32`, `i64`, `u8`, `u16`, `u32`, `u64`, `usize` (`0..2^32-1` != `u32`), `f32`, `f64` (`number` alias). `i64`/`u64` use plain contextual lits (no `1n` `E1000`), map to JS `bigint` via `js.decode`/`encode`, banned (`E2002`) in `JSON.stringify`.
- **Casts**: `i32(x)`, `usize(x)`, etc.; int casts keep in-range int lits & lit-only bitwise exprs (incl. ternaries) at target; OOR/float converts dynamically & traps `T003`; `f32` rounds binary32.
- **Literals**: Contextually typed (annot, sibling, cmp, param, elem, index=`usize`, ternary; propagates thru arithmetic/bitwise lit exprs and `wrapAdd/Sub/Mul`/`divTrunc`/`rem` + binary num ops); else `f64` (untyped bitwise->`f64`->`E2002`). Unary `-`+lit=one lit (`-0`->`+0` ints). Non-int in int ctx/OOR/non-finite (`1e400`)->`E2008` (use `Number.POSITIVE_INFINITY`/`NEGATIVE_INFINITY`/`NaN`).
- **Ops**: `+ - *` same num (`E2003`, int ovf `T001`), `+`/`+=` also *managed* `string` (`strict`/`rt` `E4001`, `string+num`/`lit+=` `E2002`); `/` float (`E2007`); `%`/`%=` float (`fmod`, `f32` rnd) or same-int (`rem`, div0 `T007`, `MIN%-1===0`); `**` float (`E2002` int, `strict`/`rt` `E4001`); same-int `divTrunc`/`rem` (`T007`/`T001`), `wrapAdd`/`wrapSub`/`wrapMul` (wrapping); unary `-` signed num (`T001`, unsig `E2002`). `f32` rounds per op. `++`/`--`: stmt/`for` step only (`+=1`/`-=1`, `T001`; val pos `E1000`). Bitwise `&|^`/`&=`.. (`u8`/`u16`/`i32`/`u32`/`i64`/`u64`), `~`/`<<`/`<<=` (`i32`/`u32`/`i64`/`u64`), `>>`/`>>=` (`i32`/`i64`), `>>>`/`>>>=` (`u32`/`u64`); shift!=`0..31`/`0..63` `T009`, `<<` truncates. `??=` (`T|null` LHS), `||=`/`&&=` (`boolean` LHS/RHS) (all layers, 1-eval LHS, short-circuit RHS). `< <= > >=`: same num or *managed* `string`/lit (UTF-16; `strict`/`rt` `E4001`; else `E2002`). Conds: `boolean` (`E2004`).

### 3.2 Capabilities & Bounds
Bounds **never inferred**: `T extends C` or `C1 & C2` (`&` only in tparam `extends` `E1000`; `Copy & Owned` `E2002`).
`Copy` (dup), `Native` (`strict`/`rt`/C/Wasm), `Owned` (`Native & !Copy`, move-only), `Send` (cross-thread), `Key` (eq/hash), `Codec` (`cast`/`js.decode`/`encode`/`JSON.stringify`), `Disposable` (`using`, `managed`/`strict`), `AsyncDisposable` (`await using`, `managed`).
Defaults: `managed` `<T>` => `!Owned` (`Owned` arg `E3007`); `strict`/`rt` `<T>` => `Native` (`E4002`); user `interface` bounds: `managed`-only.

### 3.4 Capability Rules by Construct
- `Vec`/`Slice`/`Pool`/`Handle`/`ArenaBuf`: `T extends Native & Copy` (`Arena.alloc<T>`: concrete `T` `E2002`).
- `Ring*`: `T extends Native & Copy & Send` (no `ArenaBuf`). `Port`/`spawn.isolate`: `S extends Send, R extends Send`. `audio.open<S>`: `S extends Native & Send` excl. `Result<Owned,E>`, `Ptr*`, `ArenaBuf` (`E2013`).
- `Ref<T>`/`Mut<T>`/`OwnedCell<T>`: `T extends Owned` (`Ref`/`Mut` also `Slice<U extends Native & Copy>`).
- `strict`/`rt` vals: `Native` (auths `strict`-only, `rt` `E4006`). `OwnedStruct` fields: `Native` excl. `Result<Owned,E>` (any non-`Copy` union), `Slice`, `Ref`/`Mut` (`E4002`/`E3004`; enforced thru aliases).
- `Map`/`Set`/`.includes`/`.indexOf`: `K extends Key`. `cast`/`js.decode`/`js.callback`: concrete `T extends Codec` (`E2002`). `js.encode`: `T extends Codec`. `JSON.stringify`: concrete `T extends Codec` sans `i64`/`u64` (`E2002`).
- `===`/`!==`: any `T|null` vs `null`; else `Key`, `Handle<T>`, `class`(ref), or `T|null` of those (`E2002`; `==`/`!=` `E1002`).
- `t.eq<T>`: Generic `Codec`/`Copy`. Direct: `Codec`, `Map`, `Set`, `Handle`, `ArenaBuf`, `class` (no `Owned`/fn/auth).
- `Ptr.box<T>`(unsafe): JS-free `Native` (`Copy`, `Ring*`, `CHandle`, or `OwnedStruct` of them; no `Vec`/`Pool`/`Arena` `E4007`).

### 3.5 Composites, Subtyping & Forbidden TS
- **Records/`OwnedStruct`**: Closed; no `?`(`E1008`), excess props, or dup keys (`E1000`). Spread `{...a,k:v}` needs context (dup `E1000`). `{readonly...}` (`Copy`), `OwnedStruct<{...}>` (always `Owned`, move-only, distinct from `{readonly...}`).
- **Unions/`Result`**: Tagged (distinct str-lit `kind`, no lone surr `E2012`), str-lit, `T|null`. Shared fields readable; writable iff identical non-`readonly` in all (`E2002`). `Result<T,E>`=`{readonly kind:"ok";readonly value:T}|{readonly kind:"err";readonly error:E}`; `Result.ok`/`Result.err` need context (`E2006`); carries `Owned` (move-only; post-narrow `r.value`/`r.error` read/move moves `r`; `Native` iff `T`&`E` `Native`).
- **Classes/Interfaces**: Single-level nominal `class` (no `extends` `E1000`, `implements` OK incl. `ns.Iface`, no `abstract`/accessors/index-sigs/`#private`; `private`/`readonly`/`static` OK; ctor param props `private`/`public`/`readonly` OK with `public` allowed only there, definite init, no `Ref`/`Mut` `E3004` / `Owned` `E3007`; def-init `E2002`; methods `managed`/call-only, `async` OK, no directives; `new C(...)`/`new ns.C(...)`). `interface`: nominal method iface (method sigs only, no `extends`/dupes) OR field-only record iface (closed structural; `extends` copies fields excl. `OwnedStruct` w/ covariant matching-mut overrides, no width subtyping; mixed `E1000`). `Array<T>` invar; `ReadonlyArray<T>` covar.
- **Tuples (`managed`)**: Immutable fixed `[T0,...]`/`readonly [T0,...]`/labeled `[x:T0,...]` (non-empty `E1000`, no rest `E1000`/opt `E1008`, no `Owned` `E3007`, `strict`/`rt` `E4002`); `length:usize`, const `t[k]` / homogeneous `t[i]` (`T002`/`E2002`, write `E2002`), local/`for-of`/param destructure w/ holes `[,b]` (rest/nested/top `E1000`, default `E1008`).
- **Subtyping**: Identity + `never->T`, `T->T|null`, `null->T|null`, lit/`lit-union`->`string`, lit->`lit-union`, member->tagged, `class->interface`, `[S0,...]->[T0,...]`, `[T0,...]->ReadonlyArray<U>`, `Array<S>/ReadonlyArray<S>->ReadonlyArray<T>` (`S->T`), fn contra/covar (src min-arity<=dst min-arity; non-rest dst rejects rest/extra params), `Ptr->ConstPtr`, fake->auth, arg-only `Vec/Ref<Vec>/Mut<Vec>->Ref<Slice>/Mut<Slice>` & `Mut<X>->Ref<X>`.
- **Params & Forbidden TS (`E1000` unless noted)**: Trailing defaults (`x:T=expr`, `undefined`-free), trailing `...rest:Array<T>` (`managed`-only, `strict`/`rt`/`c:` `E1000`, call spread `f(...xs)`/`Math.min|max(...xs)` `managed` `Array`/`ReadonlyArray` at rest pos `E4001`), param destructuring (`({a,b:c}:R)` all; `([a,b]:T)` `managed`, no param-prop/default `E1008`/rest/nested). Defaults banned on `c:`/iface/fn-type (`E1008`), `strict`/`rt` fn-param (`E4003`); defaults+rest banned on `cfn`/`isolate`/`audio.open`/`Resource.own*`/`forAll`. **Forbidden**: `any`(`E1004`), `object`, `Function`, `{}`, `symbol`, `bigint`, `enum`, `namespace`, `as`(`E1005`), `!`(`E1006`), `satisfies`, `is`, `asserts`, overloads, merging, `declare`(except `c:`), conditional/mapped/template/indexed types, `keyof`, `typeof`, utility types, non-`readonly[]`/`readonly[...]` ops (`E1000`), `?`/destructure defaults (`E1008`), destructuring assign, `var`(`E1001`), `throw`/`try`/`catch`/`finally`(`E1007`), `with`/`eval`/`delete`/`in`/`instanceof`/`void` op/comma/`arguments`/generators/`for..in`/regex flags!=`imsu`/`new RegExp`/tagged templates/unscoped `this`.

## 4. Statements, Expressions & Narrowing
- **Control**: `const`, `let`(init req), `using`/`await using` (block/`switch`-clause only, else `E1000`), `if/else`, `while`, `do/while`, `for(;;)`, `for(const|let x of c)` (`Array`/`ReadonlyArray`/`Set`/`Map`/`Map.keys()/values()/entries()`, incl. tuple destructure), `switch` (exhaustive `E2005`: all members/`true`+`false`/`default`; `case` lits or lit-init `const`s; per-case block scope; non-empty fallthrough `E2002`, empty fallthrough OK), `lbl:` on loops only (fn-scoped, no dupes `E1000`), `break [lbl]`, `continue [lbl]`, `return`. Non-`void` fallthrough `E2002`.
- **Narrowing**: `=== null`/`!== null`, `.kind === "..."`, lit `===`, `switch`, `&&`/`||`/`!`, early `return`/`panic`, `=`/`??=` narrow `readonly`-path locals/params; redundant null check `E2002`, unsigned `>= 0`/`< 0` (and flipped) `E2002`. `?.` on `T|null` prop/method/index (`?.[i]` read-only, effectively `managed`-only as strict/rt unions need `Copy` `E4002`) & `f?.()` (`managed` only; strict/rt `E4001`); `??` needs `T|null` LHS.
- **Literals/`new`/Arrows**: Arrow/fn-expr params infer from context (`arr.map`, typed binding, `ensures`, `test`), else/unresolved tparam `E2006`; ret inferred. Untyped `{...}`/`[]`/`[null]`: `E2006`. Templates & `String(x)` (`managed`, `string`/num/`boolean`; lit allowed in templates; `String` value ref `E2000`), regex `/pat/flags` (`managed` `E4001`, flags `imsu` `E1000`), `string+string`/`+=` (`managed`, `strict`/`rt` `E4001`, `string+num` `E2002`), `new C(...)`/`new Set<K>(iter?)`/`new Map<K,V>()` (`managed`, `new RegExp` `E2002`).
- **Async (`managed`)**: `Promise<T>` only as `await` operand (incl. `await (c?g():h())`), `Promise.all([...])` elem, or async `return` (`E2002`); unawaited `Promise` `E2002`. Eval: left-to-right.

## 5. Ownership, Borrowing & `using`
- **Moves (`E3001`–`E3003`, `E3007`)**: `Owned` moves on assign, by-val arg, `return`, `OwnedStruct` field, spread src, `Result.ok`/`Result.err`, `const`/param `{a,b:c}`. Member move of `Owned` field or partial `OwnedStruct` destructuring omitting any `Owned` field -> `E3003` (omitting `Copy` fields OK, consuming parent; moving `Owned` field out of `Ref`/`Mut` param -> `E3004`; narrowed `Result<Owned,E>` `r.value`/`r.error` move consumes `r`). Reuse after move: `E3001` (`let` reassignable). Loop move w/o same-iter reassign: `E3002`. `Owned` in `Array`/`Map`/`Set`/`Promise`/tuples/managed recs/classes, unconstrained managed generics, or closure capture: `E3007`. `Vec`/`Pool`/`Arena` are host-GC reclaimed across boundary when unreferenced; `CHandle`/`Ptr.box` lack auto-destructor and need `using`/`Resource`.
- **Borrows (`E3004`–`E3006`, `E3008`)**: `Ref<T>`/`Mut<T>` only as full param type of non-`async` fns (`E3004` elsewhere, incl. bare `Slice<U>`). Destructuring only `Copy` fields from `Ref`/`Mut` reads w/o move. Args need places (`E3008`: local, borrow param, field path, `v.borrowSlice`, `a.view`, `p.slice`, `p.borrow()`, `r.borrow()`; `p.unbox()` requires local/param, opt thru `offset`/`cast`), valid only in arg/recv slot (`E3004`, incl. `v.borrowSlice(0,2)[0]=1`). `Ref->Mut` `E3006`. **Exclusivity (`E3005`)**: `Mut` arg (and assignment LHS) forbids overlapping prefix paths of same root; same root+path `v.borrowSlice`/`a.view` runtime overlap `T013` (`Ptr.slice` static `E3005`).
- **`OwnedCell<T extends Owned>`** (`managed`): Single-owner cell (`T008` on empty/conflict/re-entrant ops, unlocks on exit/trap); re-entrant `withRef` OK; `withRef`/`withMut` ret forbids `Promise`; direct inline non-`async` callbacks may capture outer `Ref`/`Mut` (`E3005` applies; escaping `E3004`).
- **`using` / `await using`**: LIFO cleanup on any exit (normal/`break`/`continue`/`return`/trap). `managed` `using`: `Disposable`; `await using`: `AsyncDisposable`. `Resource.own`/`ownWith` only in `using r = ...` (`rt`: zero-alloc stack defer; `T`: `Owned` or unsafe `Ptr`/`ConstPtr`; `strict`/`rt` cleanup is top non-generic `strict`/`rt` fn, unsafe iff caller unsafe; `ctx`: `Ffi`/`Alloc` `strict`-only or `Native & Copy`). `Resource<T>` cannot escape (`E3004`); `r.borrow()`/`r.get()`/`r.take()` (disarms cleanup; post-take `E3001`).

## 6. Native Containers (`strict` / `rt`)
OOB `T002`; `.create`/`.filled` OOM `T006`; process-unique Pool/Arena IDs; `u32` gens (Pool LIFO `T011`; `Arena.view` `T012`). Sigs: `docs/STDLIB.md`.
`Vec` (alloc: `.create`/`.filled`/`push` `E4004`), `Slice`, `Pool` (`Handle<T>` `===`), `Arena` (`alloc<T>`: concrete `T` `E2002`), `Ring` (`Ring.create` alloc; `cap` 2^k in `1..2^31` `T014`; `RingPair<T>`=`OwnedStruct<{tx:RingTx<T>;rx:RingRx<T>}>`).

- **Entry**: `export function main(sys: System): void | Promise<void>` (`managed`). `System`: `Alloc`, `Fs`, `Clock`, `Random`, `Log`, `Js`, `Ffi`, `Spawn`, `Audio`, `Display`, `Net`, `Proc` (`managed`-storable; ambient globals `E5001`). Handles (`AsyncDisposable`): `AudioStream`, `DisplaySurface`, `HttpServer`. Records/unions: `IoError`, `CastError`, `JsError`, `AudioConfig`, `DisplayConfig`, `DisplayColor`, `DisplayEvent`, `DirEntry`, `FileStat`, `EnvVar`, `ProcOptions`, `ProcOutput`, `ProcRequest`, `HttpHeader`, `HttpRequestInit`, `HttpResponse`, `HttpServerConfig`, `HttpServerRequest`, `HttpServerResponse`, `HttpBody`, `HttpServerRawResponse`, `HttpClientRequest`, `QueryParam`, `RegExpMatch`. Fakes (type+ns, cap-assignable; none for `Js`/`Ffi`): `FakeClock`, `SeededRandom`, `MemoryLog`, `FakeFs`, `FakeSpawn`, `TestAlloc`, `FakeAudio`, `FakeDisplay`, `FakeNet`, `FakeProc`. Sigs: `docs/STDLIB.md`.
- **`Pure`**: Deterministic safe fn, local/`this` mut OK; no auth/`fn`/nominal `interface`/`unknown`/`JsRef`/`Ptr*`/`CHandle`/`Ring*`/`Port`/`AudioStream`/`DisplaySurface`/fake anywhere in **params OR ret** (+ class fields for methods).
- **`Mutatable`**: Safe top fns/`class` methods not touching `Test`, excluding `System`/`Ffi`/`Js`/`JsRef`/`Ptr*`/`CHandle` in **params OR ret** (`Alloc`/`Spawn`/`Port`/fakes/single-thread `Ring*` OK).
- **`npm:` (`managed`)**: Named, default, ns (`* as ns`), combined ESM/CJS bind `JsRef` (throws->`JsError`; `js.callback` traps unwind; `import type` on `npm:` `E7001`).

## 8. Concurrency & Portable Audio
- **Rings**: `SharedArrayBuffer`+`Atomics` or `MessagePort`.
- **Isolates (`managed`)**: `spawn.isolate<S extends Send, R extends Send>(f): Port<S, R>` takes top non-generic `managed` fn `(port:Port<R,S>[,alloc:Alloc])=>void|Promise<void>` (`E2011`; bad `S`/`R` `E2010`). `Owned` `R`: `port.recv()` only under `await`; bind & narrow `!== null` before move. `port.close()` is a full close on caller's handle (drains queued msgs then `recv()` returns `null`; call after reading expected replies). `main` exit stops isolates. `FakeSpawn`: in-process async `Port` pack/unpack, trap prop, `T006` deadlock check.
- **Audio (`managed`)**: `audio.open` moves `state:S` (excl. `Result<Owned,E>`/`Ptr*`/`ArenaBuf` `E2013`); `render` top non-generic safe `"use rt"` `(st:Mut<S>|S, out:Mut<Slice<f32>>, frames:usize):void` (`Mut<S>` if `Owned`; `out.length===frames*channels`, interleaved, zeroed).
- **Cross-thread traps**: First trap sets atomic flag; surfaces on main at earliest of `strict`/`rt` ret, `await`/`recv`, or `main` exit. `cfn`/audio emit silence once set.

## 9. C FFI & `"use unsafe"`
- `declare module "c:<pkg>:<header>" { ... }` (`<pkg>` must exist in `pkg-config`, no `libc.pc`—declare `<stdlib.h>` under an active `.pc` pkg e.g. `"c:zlib:stdlib.h"`; non-empty, no space/ctrl/`:`/`<`/`>`/`"`/`\`: `E7002`; 1/spec/file; must import in declaring file `E7002`): `function f(ffi:Ffi,...):R;` (`Ffi` omitted in C & `rt+unsafe`, passed in `strict+unsafe`; rest num/`boolean`/`Ptr`/`ConstPtr`, ret same/`void` `E4007`); `const NAME:T;` (`i8..u64|usize|f32|f64|boolean`); `type S=CStruct<{field:FieldT;...}>;` (`FieldT`: num/`boolean`/`Ptr`/`ConstPtr`/`CType`/`CStruct`; pointees allow `void`).

## 10. Contracts, Testing, `forAll` & `szigyr mutate`
- **Contracts (`E6001` pos, `E6002` ref/mut/nondet)**: `requires(cond)` (fn top, params), `ensures((r:R)=>bool)` (fn/method only, after `requires`, `r`+params incl. `Ref`/`Mut` post-state; by-val `Owned` params `E6002`), `invariant(cond)` (loop top). `Pure` observe-only (no assigns/mutators/`Owned` moves/`Mut` borrows/`cfn`). - **Tests (`E6003`)**: Top-level `test("name",(t:Test)=>{...})` (`async` OK, `managed`, stripped outside `test`/`mutate`, use fakes); `test --all` runs imported `test(...)` (deduped); `--filter=<pat>` case-insensitive.
- **`forAll` & `fuzzContracts` (`E6004`/`E6005`)**: Inside `test(...)` (`E6004`); 100 runs (max 1,000 top-`requires` skips else fail), deterministic RNG, shrinks counterexamples; `forAll((a:A,...)=>boolean|void)` (annotated inline predicate, fails on `false`/trap, optional leading `requires`); `fuzzContracts(fn)` (safe top non-generic non-async fn, checks contracts/no-trap, return value ignored); generatable: prims/nums (!`unknown`/`never`), lit/tagged unions, records, tuples, `OwnedStruct`, `Array`/`ReadonlyArray`, `Set`/`Map`, `Vec`/`Slice` (+ `Ref`/`Mut` of `OwnedStruct`/`Vec`/`Slice`).
- **`szigyr mutate`**: Single-build JS over `Mutatable` fns/classes (`c:`/unsafe stubbed); `--all` deduped; `--fail-on-survived` exits `1` iff `survived>0` (`timeout` exits `0`); `c:`/unsafe-reaching `test` skipped->`summary.skippedTests`. 6 ops (`+`/`-`/`*`, cmp, `&&`/`||`, `if` bool, `0`/`1`/bool lit, expr-stmt del->`deadCode`), skipping eq `Vec.create` cap hints, min/max/clamp/abs ties, active narrowing guards, nonzero `for` step (`x+=k`/`-=k->0`), overwritten inits. - **`szigyr prove` & `--release`**: Async per-fn SMT-LIB2 (`SZIGYR_SMT`/`z3`/`cvc5`, Wasm `z3-solver` fallback) over safe top `strict`/`rt` (incl. parametric generic fns) and contracted fns w/o fn params (excl. `unsafe`, fn-param fns, `class` methods; `--all` deduped) for `T001`/`T002`/`T003`/`T004`/`T005`/`T007`/`T009`/`T010` (unsigned `&`/`|`/`^` & non-neg signed `&` & `Vec`/`Slice`/`ArenaBuf.length` + `Arena.alloc`/`view` modeled; floats/indexed elems `s[i]`/unmodeled yield `unknown` only if VC depends on them; canonical counting `for` loops synthesize counter auto-invariants (other loop-carried vars need `invariant`)).
