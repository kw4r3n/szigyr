# 診断とトラップのコード

「コード」と「意味」の列は `docs/SPEC.md` §11 と §8 の写し。意味は変えない。コードの追加は連番で行い、追加したらこの表と SPEC の両方に書く。

## 位置の数え方

- 行・列は 1 始まり。列は UTF-16 符号単位で数え、タブも 1 と数える。BOM は数えない（Q001）。
- `range.start` は下の表の「アンカー」が指すノードかトークンの先頭で、前置トリビアは除く（`node.getStart()`）。`range.end` は排他的（Q001）。
- 表にない形には Q002 の一般則を適用する。
- 「最初の診断」は、ハーネスが全診断を (line, col, code) でソートした先頭とする。コンパイラはフェーズ P1 → P2 → P3 の順に検査し、エラーが出たフェーズで止まる（Q003）。
- 拒否ケースのファイルには違反を 1 つだけ書く（Q003）。
- 「Q」列の項目は既定案であり、SPEC が決めたものではない。
